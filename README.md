# Jev × ChatGPT Finance Manager guide

[Read the guide](https://vibha-ramprakash.github.io/expense-manager-jev-chatgpt/) · [Standalone ChatGPT plugin setup](https://vibha-ramprakash.github.io/expense-manager-jev-chatgpt/plugin.html)

A public setup guide with copyable prompts, 5,000 fictional transactions, subscription usage evidence and review/forecast skills.

This repository contains the guide and starter data, not an installable ChatGPT plugin. Create and privately publish your own Finance Manager Site, then install the plugin generated for it. Personal/Pro Site plugins do not currently offer public sharing links; see the sourced instructions on the plugin page.

All sample expense records are fictional. Vendor prices are illustrative. No credentials, private board data or live-run receipts are included.
