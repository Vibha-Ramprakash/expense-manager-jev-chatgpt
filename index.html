Before you start

What you’ll need

  • ChatGPT/Codex with the /Sites plugin available. Workspace permissions may apply.
  • A TypeSafe account and Jev API key. API usage is billed separately; confirm current rates in your account.
  • Your statement CSVs, or the fictional practice files below. This example uses CHF.
Enter your API key only in the app’s masked connection field. Never paste it into a prompt, screenshot, source file or shared download. Redact full card and account numbers from statements.
01

Connect Jev

Open Codex in ChatGPT and use this prompt. Ask for the key field, then enter your TypeSafe key there. Start with a 20-row access test before running a full dataset.

Open the full copy-and-paste prompt
Build a private Finance Manager with an Expense X-Ray tab. Use TypeSafe direct, model jev-latest, following the current official TypeSafe System One API documentation. Ask me to enter my API key through a masked field; never put it in chat, source, logs, exports or persistent browser storage. Keep it in tab memory and send it only to a same-origin server endpoint which calls TypeSafe. First test 20 rows, then let me explicitly start the full run. Use real provider responses only: show elapsed classification time, number of returned decisions, confidence and input-token usage. Show provider-reported cost when present; otherwise label cost as an estimate using the documented rate. Export a receipt with scope, model, rate, token usage, elapsed time and errors. Never invent a successful result, accuracy, timer or cost. Preserve incomplete results on failure and distinguish a test from the full benchmark. Build the app with a cream background, berry accents and readable tables.
02

Drop your statements in

Drop the expense CSV and optional usage CSV onto Expense X-Ray—or choose files/folder. If using Drive, connect it in your agent or download the files first. The supplied practice set contains exactly 5,000 expenses across October 2023–September 2026.

Open the full copy-and-paste prompt
Import all statement CSVs from my selected folder into Finance Manager. If I choose Google Drive, ask me to connect Drive and select the exact folder; if access is unavailable, help me download the CSVs. Do not claim access to an unconnected folder. Extract text PDFs with reconciliation checks; ask for CSV/OCR when a PDF cannot be parsed reliably. Preserve original transaction IDs, dates, merchants, descriptions, amounts, currency and cardholder; deduplicate copies by transaction ID, but flag possible duplicate charges separately. Remove full card/account numbers before classification. Send only the minimum needed fields to Jev. Classify every line into software, travel, meals, office, marketing, contractors, training, transfer, personal or other. Keep confidence and route low-confidence, personal and context-poor rows to human review. Never call confidence measured accuracy. Separate refunds, transfers and personal charges from business totals. Import the supplied SaaS usage export as separate evidence: transactions alone cannot tell you a subscription is unused. Keep synthetic demo data clearly labelled. Preserve raw evidence and allow corrections and CSV export.

Check the row count, then click Run Expense X-Ray. Review flagged rows and sample-check confident ones too. Confidence is not proven accuracy. Export the receipt and corrected CSV.

03

Build with the /Sites plugin

Create a ChatGPT project called Finance Manager. Select the /Sites plugin, attach your classified data and the Forecast skill, and paste this prompt. Preview the app, then publish your own private Site.

Open the full copy-and-paste prompt
Use the /Sites plugin to build and privately publish my Finance Manager from the classified expense data. Include five connected tabs: Expense X-Ray, Team spending, Subscriptions, Forecast, and Ask Finance Manager. Store each signed-in user's saved board separately. Show month and employee filters, possible duplicate groups, personal charges, recurring subscriptions, dated usage evidence, cancellation-email drafts and a twelve-month forecast with editable assumptions and a before/after cancellation scenario. Use the attached Forecast skill. Show transaction-level evidence behind every insight. Never send emails or cancel a subscription automatically. Keep API keys server-safe and out of persistence. Label synthetic sample data, model estimates, incomplete classifications and hypothetical savings. Include the exact demo question: Why did my software spending go up in August? Compare August 2026 against July 2026 and show each vendor's contribution, linked transaction IDs, and what the statements cannot establish. Provide a reliable preview and retain the same saved board for the ChatGPT plugin.

Click Save board on your hosted app. Your ChatGPT plugin reads that saved board; changes in another local copy are not automatically synchronized.

What to trust—and what to review

Subscriptions, forecasts and cancellation drafts
A recurring charge does not prove a subscription is unused. The practice usage report identifies Asana, Miro and Loom as zero-user candidates over its stated 90-day window. They total CHF 286/month. Canceling all three in the sample scenario reduces twelve-month spending by CHF 3,432, before notice periods and replacement costs. Forecasts use observed history and explicit assumptions. No email is sent or subscription canceled automatically.
Measuring your own run
Record the full-run receipt: requested and classified rows, errors, input tokens, elapsed seconds and provider cost or labeled estimate. The timer measures classification including network/batching, not app building, import or review. Row animation may finish after the timer freezes. A pilot is not the full benchmark. Results and costs vary; use your own receipt.
If something does not work
No /Sites option? Check account availability and workspace permissions. Key rejected? Use a TypeSafe direct key, not an OpenRouter key. PDF will not import? Use the CSV or a verified extraction/OCR process. Plugin cannot see edits? Save the hosted board using the same account, then reconnect the plugin if needed. This example is an expense-review tool, not a complete accounting ledger or tax filing system.
